The gap buyers still feel

“Personalised” usually means difficulty and sequencing. Pedagogy stays fixed — or relies on learning-style quizzes that research does not support.

Same wrong answer Two kids fail the same item for different reasons. One explanation rarely fits both.
Practice looks fine Scaffolded practice scores high. Unassisted checks later expose that it never stuck.
Expertise flips Beginners often need worked examples. Stronger learners need less guidance — so the best method changes.
Your stack already has content You don’t need another library. You need a method layer on top.

One continuous loop

We do not label children with learning styles. We measure which method reaches delayed mastery for this learner right now — then we change as they grow.

1 · Find the gap Adaptive quiz → weak skill + likely mix-up.
2 · Choose how to teach Policy picks among worked example, problem-first, visual, or story.
3 · Teach + verify Lesson matched to that style; numeric answers SymPy-checked.
4 · No-help check Unassisted review is the reward — practice scores never train the policy.

Finds better methods faster

On ASSISTments fraction parameters (100 simulated learners), the contextual bandit reaches mastery in fewer sessions than fixed or random method assignment — and recovers true preferences over time.
