# 10-minute meeting runbook — AI video schools

**Open:** `streamlit run app.py` → **Show results demo →**

| Min | Screen | Say |
|-----|--------|-----|
| 0–1 | Landing | “You generate AI videos. We make the next one personal — so you render less.” |
| 1–3 | Their system | Walk generate → watch → quiz → next. Point at **11 min** generic brief. |
| 3–4 | Evaluate | Click **Use meeting snapshot**. Name weak spot + mix-up + style. |
| 4–7 | Short brief | Side-by-side minutes + open the scene list. “This JSON goes to your generator.” |
| 7–9 | Results board | Live case metrics + cohort cost proxy + matched vs mismatched delayed. Honesty line once. |
| 9–10 | Ask | 90-day embed after their quiz for one skill. Success = minutes ↓ + mastery ↑. |

**Backup numbers** (from `outputs/buyer_demo/`):

- Cohort specialised/generic cost ratio ≈ **0.27**
- Matched style delayed mean ≈ **56%** vs mismatched ≈ **28%** (Qwen agents — pipeline proof)

**Do not lead with:** recruit volunteers, long Streamlit teaching UI, claiming child RCT.

**Optional after:** Live 5-min try if someone in the room wants to feel the quiz.
